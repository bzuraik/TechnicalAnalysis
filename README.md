# TechnicalAnalysis

BDA400 course repository by Bahaa Zuraik. R code for technical analysis of stock data.

- `A2_Preliminary_Stage`: portfolio.txt, load_stock_data(), calculate_statistics() and display utilities
- `A5_Development_Phase`: sma, ema, macd, stdev, linreg, rsi, stoch_rsi, crossover, crossunder (no libraries)
- `A6_Visualization_Phase`: Shiny dashboard (app.R) with date-range and time-frame widgets, indicators, and MA-crossover signals
